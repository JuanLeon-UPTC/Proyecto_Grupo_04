## Pregunta de lectura
¿Qué debe tener una ficha de requisito y una matriz de trazabilidad para que un requisito del proyecto sea verificable y rastreable hasta su origen?

## Alcance y conformidad
Define el proceso de ingeniería de requisitos dentro del ciclo de vida de sistemas y software: qué documentos produce (StRS, SyRS, SRS y los complementarios BRS y OpsCon), qué características debe tener cada requisito individual (nueve pruebas) y el conjunto completo (cinco características), y cómo mantener la trazabilidad. No exige un formato de documento único; permite adaptación según el tamaño del proyecto. Declarar conformidad total implicaría producir toda la cadena documental; el proyecto declara conformidad **parcial** (ver matriz de adaptaciones).

## Términos clave
| Término | Definición en palabras propias |
|---|---|
| StRS | Documento de necesidades de los interesados (Stakeholder Requirements) |
| SyRS | Documento de requisitos del sistema completo (incluye hardware si aplica) |
| SRS | Documento de requisitos del software — el que construye este proyecto |
| Requisito verificable | Se puede escribir un criterio de aceptación sin discutirlo |
| Trazabilidad bidireccional | Cada requisito tiene su origen y su destino (verificación) enlazados |
| Las nueve pruebas | Necesario, apropiado, no ambiguo, completo, singular, factible, verificable, correcto, conforme |

## Estructura (de alto nivel, según la descripción del curso)
- Marco del proceso de requisitos (informativo para este proyecto: orienta, no se exige literal)
- Características de requisitos individuales y de conjunto (normativo: se aplican las nueve pruebas)
- Guía de contenido de los documentos StRS/SyRS/SRS (parcialmente normativo: solo se usa para el SRS)

## Qué debemos producir / cómo lo revisamos
El equipo produce solo el **SRS** (no StRS ni SyRS separados, por el tamaño del proyecto — ver tabla de adaptaciones de la matriz). Se revisa aplicando las nueve pruebas a cada requisito y las cinco características de conjunto al documento completo, en la Sesión 3.
