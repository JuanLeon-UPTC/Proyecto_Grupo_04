# Declaración de aplicación de estándares · v0.1

Proyecto Grupo 04 — Sistema de registro de ventas (Panadería El Arte de Amar)
2026-11-15

El equipo declara lo siguiente sobre el uso de estándares en este proyecto académico:

1. **Se adopta** ISO/IEC/IEEE 29148:2018 como referencia central para escribir y trazar requisitos, de forma parcial: solo se produce el documento SRS (no StRS ni SyRS separados), por el tamaño del proyecto.
2. **Se adopta** la estructura de secciones de IEEE Std 830-1998 como plantilla del SRS, aunque el estándar esté reemplazado.
3. **Se adopta** ISO/IEC 25010:2023 como catálogo de características de calidad para redactar los requisitos no funcionales.
4. **Se adoptan los hábitos mínimos** de ISO/IEC 29110 (identificador, fuente, prioridad, criterio verificable, estado, trazabilidad), por ser un equipo de 3 personas.
5. **No se declara conformidad** con ISO 9001, ISO/IEC/IEEE 90003, ISO/IEC/IEEE 15288 ni CMMI V3.0, por ser desproporcionados para el tamaño, el alcance y la naturaleza puramente académica del proyecto.
6. **Se cumple** (no se adapta, por ser ley) la Ley 1581 de 2012 en lo mínimo que aplica (dato personal del empleado).
7. **No aplica.** La Resolución DIAN 000165 de 2023 (facturación electrónica) queda declarada fuera de alcance: ningún caso de uso ni historia de usuario la requiere, y el acta no la incluye. No se implementará en este proyecto.

Esta es una versión preliminar (v0.1); se revisa y cierra en la Sesión 5 de esta unidad, dentro del plan de adopción de estándares.
