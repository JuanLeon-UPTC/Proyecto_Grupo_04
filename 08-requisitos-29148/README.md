# Unidad 4 · Sesión 3 — Requisitos y trazabilidad (ISO/IEC/IEEE 29148)

Proyecto Grupo 04 — Sistema de registro de ventas

## Decisión sobre el SyRS
**No se produce un SyRS separado.** El proyecto es puramente software (confirmado en la matriz de aplicabilidad, Sesión 1: pregunta de contexto 6 — no hay hardware, personas ni instalaciones propias del sistema que especificar aparte de las que ya cubre el SRS). Por la misma razón, tampoco se produce un StRS como documento separado: la lista de necesidades (`strs-necesidades.md`) cumple esa función sin ser un documento aparte formal, ni un OpsCon — es una adaptación declarada en la Sesión 1 (ver `06-estandares-mapa/matriz-aplicabilidad.md`, tabla de adaptaciones).
