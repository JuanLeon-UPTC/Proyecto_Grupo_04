# Glosario · Sesión 3 (Unidad 4)

El glosario completo del dominio del negocio ya existe en `15-dominio-consistencia/glosario.md` (Unidad 5, Sesión 5) y no se duplica aquí. Esta sección agrega solo los términos nuevos que introduce esta sesión, propios de la ingeniería de requisitos (no del negocio):

| Término | Definición |
|---|---|
| NI | Necesidad del interesado — lo que alguien necesita, antes de convertirse en meta o requisito |
| StRS | Documento de necesidades de los interesados (Stakeholder Requirements Specification) |
| SyRS | Documento de requisitos de todo el sistema (incluye hardware, si lo hay) |
| SRS | Documento de requisitos del software — `07-srs-830/srs.md` en este proyecto |
| OpsCon | Concepto de operación — cómo se usará el sistema en el día a día; no se produce en este proyecto (ver decisión en `README.md` de esta sesión) |
| Las nueve pruebas | Necesario, apropiado, no ambiguo, completo, singular, factible, verificable, correcto, conforme |
| Las cinco características de conjunto | Completo, consistente, factible, comprensible, validable |
