# Storyboard · F-01 Registrar una venta (flujo más crítico)

Descripción en viñetas (los wireframes visuales se hacen en la Sesión 3; este storyboard es la base para dibujarlos).

1. **P-01 vacía.** La cajera ve un espacio para indicar producto y cantidad, y el total en $0.
2. **Agrega "Pan de sal" x2.** La pantalla muestra la línea agregada y el subtotal actualizado.
3. **Agrega "Croissant" x1.** Segunda línea, subtotal sigue creciendo.
4. **Marca venta completa.** La pantalla cambia a modo "lista para cobrar", muestra el total y un botón grande de confirmar pago.
5. **Confirma el pago.** Aparece M-03 ("Venta registrada") brevemente, y la pantalla vuelve al estado vacío para la siguiente venta.
