## 8. Glosario (Apéndice A)

| Término | Definición |
|---|---|
| Venta | Operación confirmada que registra uno o más productos entregados al cliente y sus valores. |
| Detalle de venta | Línea que relaciona un producto, cantidad y precio unitario aplicado. |
| Precio vigente | Precio del catálogo aplicable al momento de confirmar la venta. |
| Producto disponible | Producto activo que puede seleccionarse para una nueva venta. |
| Producto inactivo | Producto conservado en el historial, pero no seleccionable para ventas nuevas. |
| Inventario | Existencia operativa registrada de un producto; no equivale a contabilidad de costos. |
| Movimiento de inventario | Entrada, salida o ajuste documentado de existencias. |
| Rotación | Cantidad de unidades vendidas de un producto durante un periodo. |
| Histórico | Conjunto de ventas válidas registradas hasta la fecha de consulta. |
| Sugerencia de producción | Estimación calculada a partir de ventas anteriores; requiere decisión humana. |
| Baja rotación | Clasificación relativa de productos con pocas unidades vendidas frente a los demás en el periodo. |
| Anulación | Cambio controlado del estado de una venta confirmada, sin borrar su registro original. |
| Cierre diario | Corte lógico de consulta y consolidación de las ventas de una fecha local. |
| Usuario activo | Cuenta habilitada para autenticarse y operar según su rol. |
| COP | Peso colombiano, unidad monetaria utilizada por el sistema. |
