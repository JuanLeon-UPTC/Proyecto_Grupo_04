## 3. Requisitos específicos

### 3.1 Interfaces externas

- Interfaz de usuario: navegador de escritorio compatible con Chrome y Edge actuales.
- Base de datos: motor relacional con transacciones ACID.
- Exportación: archivo CSV UTF-8 descargado por el navegador.
- No se requiere integración con pasarela de pago, DIAN ni proveedores.

### 3.2 Requisitos funcionales

Se incorporan íntegramente RF-001 a RF-022 del documento 22. La descripción normativa y sus métodos de verificación son la fuente de verdad.

### 3.3 Requisitos no funcionales

Se incorporan RNF-001 a RNF-010 del documento 22. La prueba de rendimiento se ejecutará con datos sintéticos reproducibles y luego con datos operativos anonimizados si el negocio autoriza su uso.

### 3.4 Reglas de negocio y validaciones

Se incorporan RN-01 a RN-30, V-01 a V-15 y MSG-01 a MSG-403 del documento 24. Las fichas FP-01 a FP-11 definen las pantallas y los contratos de interacción.

### 3.5 Comportamiento del sistema

Se incorporan CU-01 a CU-08, HU-01 a HU-08 y AC-01 a AC-20 del documento 23.
