## 7. Lista de verificación para publicar en GitHub

- [ ] Cada integrante revisó y aportó un commit real en su propia rama.
- [ ] Los archivos se exportaron a PDF según la convención del repositorio.
- [ ] Se generó SHA-256 de cada PDF y se incluyó en la descripción del pull request (no dentro del documento).
- [ ] El PR apunta a `main` y otro integrante revisa; nadie aprueba su propio PR.
- [ ] Se utiliza merge commit, según la convención existente del repositorio.
- [ ] `CONTRIBUCIONES.md` se actualiza con contribuciones reales.
- [ ] No se inventan firmas, reuniones ni resultados de pruebas.
